# Spello — handoff notes

Spello is a German vocabulary app (A1–B2, plus books imported from PDFs). Learners
study new words, review them on a fixed spaced-repetition schedule, and keep a pet
that ages with their study days. Coins (one per word practised per day, plus bonus
games) buy pet accessories. UI languages for meanings: English or Chinese.

- Website: https://evecui250.github.io/spello/ (GitHub Pages)
- iOS: a Capacitor shell on TestFlight that **loads the live website**. It doesn't bundle the site.
- Owner: Yingying Cui (evecui250@gmail.com). Collaborator and admin: Yutong (yutong.chen@inf.ethz.ch).

## Stack and layout

- **Next.js 15 / React 19 / Tailwind 4**, static export (`output: 'export'`, `basePath: '/spello'`, see `next.config.js`). There are no server routes; anything server-side is a Supabase Edge Function.
- `app/`: pages (`/` Home, `/practice` daily session, `/words` incl. the Mistakes tab, `/progress`, `/settings` = Profile, `/game`, `/admin`, `/welcome`, `/privacy`, `/terms`; `/pet-chat` is hidden).
- `components/`: `DailySessionFlow.tsx` is the core daily flow (review → study → congrats → bonus game). It's large.
- `lib/`:
  - `words.ts`: the whole word corpus, hand-curated and generated by `scripts/`.
  - `storage.ts`: all localStorage state.
  - `sync.ts`: Supabase sync and merge.
  - `srs.ts`, `practice.ts`: review schedule and exercise logic.
  - `ai.ts`: Edge Function client.
  - `features.ts`: feature flags.
- `supabase/functions/`: Deno Edge Functions (OpenAI calls, admin stats, reports, account deletion…). `_shared/pricing.ts` holds the per-model cost table.
- `supabase/migrations/`: SQL migrations.
- `scripts/`: Python content pipelines (translations, images, audio, verb forms). They need `OPENAI_API_KEY` and write into `lib/words.ts` and `public/`.
- `ios/`: Xcode project (CocoaPods). `capacitor.config.ts` holds `server.url`, `allowNavigation` and `appendUserAgent`.

## Run, build, deploy

```bash
npm ci
npm run dev                 # http://localhost:3000/spello/
npm run build               # static site in out/
npx tsc --noEmit -p .       # typecheck (there's no test suite)
```

- **Website:** push to `main`. `.github/workflows/deploy.yml` builds and publishes to Pages. The owner has OK'd pushing straight to main.
- **Edge Functions:** a push touching `supabase/functions/**` triggers `deploy-functions.yml`, which deploys all of them. The Supabase CLI version is pinned on purpose, because "latest" hit GitHub rate limits.
- **Database migrations are manual:** `echo y | supabase db push --linked` (project ref `whjiebzglefivvczvpfb`).
- **Reports:** `reports.yml` cron emails the admins (Mondays: weekly AI cost; the 1st: monthly cost + learner activity) via `send-report`. It can also be run by hand from the Actions tab.

## Environment variables (names only)

- **Supabase Edge Function secrets:** `OPENAI_API_KEY`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` (both auto-provided), `RESEND_API_KEY`, `REPORT_SECRET`, `REPORT_FROM`, `REPORT_EMAILS` (optional), `WEBHOOK_SECRET` (bug-report DB trigger), `NOTIFY_EMAIL`, `NOTIFY_EMAILS` / `NOTIFY_FROM` (optional), `ADMIN_EMAILS` (optional; the default lists both admins).
- **GitHub Actions secrets:** `SUPABASE_ACCESS_TOKEN`, `REPORT_SECRET` (must equal the Supabase one; rotate both together).
- **Next.js:** none needed. `NEXT_PUBLIC_BASE_PATH` and `NEXT_PUBLIC_BUILD_ID` are set by `next.config.js`. The Supabase URL and publishable key are hardcoded in `lib/supabase.ts`.
- **Scripts:** `OPENAI_API_KEY`.
- **Email:** Resend sends from the verified domain `mail.spelloapp.com` (DNS on Cloudflare).

## Conventions and gotchas

- **The iOS app loads the live site.** Web changes reach TestFlight users with no new build. Native changes (Info.plist, plugins, `capacitor.config.ts`, icon) need a new build. Older installed builds load the same new site, so web code must detect what the shell supports:
  - `Capacitor.isPluginAvailable(...)` for plugins
  - the `SpelloApp/mic` user-agent marker for the microphone (see `VoiceInputButton`)
- **Local testing writes to production.** `lib/supabase.ts` is hardcoded to the live project. In Playwright, block or mock `supabase.co` with `ctx.route`, and delete any rows a test creates (e.g. `ai_usage` rows tagged with a test id).
- **Storage is per book.** Keys are suffixed `__{level}` (`wb2_progress__A2`, `wb2_settings__A2`, `wb2_daily_session__A2`…). Switching book is a full profile switch. Account-wide keys have no suffix: `wb2_goal_days_total`, `wb2_daily_word_log`, `wb2_streak_global`, `wb2_active_level`, `wb2_onboarding_done`. Pet age counts days across all books.
- **Settings writes** must start from `getSettings()` and add the changes, or fields the page doesn't show get wiped.
- **No `useSearchParams`** (static export would need Suspense); read `window.location.search` in an effect.
- **Daily session state** lives in `DailySession` (persisted, synced, newest-wins). New phases or fields must be optional and safe to resume mid-way.
- **Words in Context** is a bonus game now. The old `study-paragraph*` phases remain only so old sessions can finish.
- **Coins** = sum of `daily_activity.words_studied` + count of `game_plays` rows − accessory costs. Adding a new `game` value needs the `game_plays_game_check` constraint widened in a migration.
- **AI cost estimates:** add new models to `supabase/functions/_shared/pricing.ts`.
- **iOS build quirks:** `npx cap sync ios` / `pod install` need `LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8`, or Ruby fails on Unicode.
- **Shell:** in zsh Bash-tool scripts, don't name variables `status` or `UID` (they're reserved).
- **Code comments:** the codebase explains *why* in comments. Match that style.
- **Confirm before** anything destructive, touching production data, or anything TestFlight-related.

## TestFlight upload

Bundle ID `com.spelloapp.app`, team `STULKPS2Z7`. The current build is 1.0 (3), which expires around 2027-01-16.

1. Bump `CURRENT_PROJECT_VERSION` in both build configs in `ios/App/App.xcodeproj/project.pbxproj`. Bump `MARKETING_VERSION` only for a new version.
2. Check that `ios/App/App/capacitor.config.json` points at the live URL (it gets swapped to localhost for simulator tests). Then run:
   `cd ios/App && xcodebuild -workspace App.xcworkspace -scheme App -configuration Release -destination 'generic/platform=iOS' -archivePath "~/Library/Developer/Xcode/Archives/<date>/Spello 1.0 (<build>).xcarchive" DEVELOPMENT_TEAM=STULKPS2Z7 -allowProvisioningUpdates archive`
3. `open` the .xcarchive. The owner clicks Distribute App → App Store Connect → Upload in Xcode Organizer (there's no API key on this Mac).

## Recent work (Nov 2026)

- **New-word flow:**
  - Swipeable preview, with a "Mastered" button per card.
  - Listen and fill in half the letters. A miss shows the answer and the card comes back at the end of the round. Check works with blanks.
  - Optional "Build a sentence" (+1 coin), with voice entry (🎤 → `transcribe-speech`).
- **Reviews:** an optional past-tense (Perfekt) step after review, on by default from A2 (`lib/pastTense.ts`). Unfinished lower-level reviews can carry over after moving up a level (`LevelCarryOver.tsx`).
- **PDF import** groups by the PDF's chapters and labels multi-word chunks `type: 'phrase'`, for a future phrase exercise. A phrase is a short chunk like "Pass auf!", never a full sentence.
- **Navigation:** the Notebook moved to Words → Mistakes (with "Clear all"). Pet chat is hidden (`PET_CHAT_ENABLED = false`).
- **Games:** bonus games unlock on the 3rd study day (`gamesUnlocked()`). Words in Context became a game.
- **Accounts and admin:** in-app "Delete my account" (`delete-account`). Emailed admin reports. Yutong added as admin. Bug-report emails go to both admins.
